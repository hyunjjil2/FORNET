내 시트 연결하기

이 대시보드는 사용자마다 자기 구글 시트에 연결돼요. 본인의 Apps Script 웹 앱 주소(.../exec로 끝나는 주소)를 한 번만 입력하면 이 브라우저가 기억해요. 다른 사람의 데이터와는 섞이지 않아요.

엑셀 업로드 형식 · 사용 안내
1) 앨비스(ERP)에서 뽑은 엑셀을 그대로 업로드하면 됩니다. 첫 행은 헤더(컬럼명)여야 하며, 아래 이름 중 하나와 일치해야 자동 인식됩니다.
2) 루틴(해상수출FCL/해상수출LCL/해상수입FCL/해상수입LCL/항공수출)을 루틴 컬럼에 넣어주면 자동으로 지정되고, 없으면 "루틴 미지정" 건으로 표시되니 직접 한 번 지정해 주세요.
3) 관리번호가 기존번호-X01처럼 "-X숫자"로 끝나면 이월·분할 청구 전용 건으로 자동 인식되어, 체크리스트 중 청구 관련 항목만 표시됩니다.
4) 재업로드 시 루틴 · 체크리스트 진행 상태는 절대 덮어쓰지 않습니다 — 이미 체크한 항목은 그대로 유지되고, ETD·ETA·담당자 등 나머지 정보만 최신화됩니다.
5) 날짜는 반드시 실제 날짜값으로 입력되어야 인식됩니다 — "TBA" 같은 텍스트는 인식되지 않습니다.
6) 이 페이지는 구글시트를 데이터베이스로 사용합니다. 화면은 약 20초마다 자동으로 최신 상태를 다시 불러옵니다 — 진짜 실시간(즉시 반영)은 아니고, 짧은 시차가 있는 "준실시간"입니다.
전체 건 목록 (관리·수정용)
완료 처리된 지 30일(수정일 기준) 지난 건을 "보관" 시트로 옮겨 대시보드 속도를 유지합니다 · 매일 새벽 자동 실행되며, 이 버튼은 지금 바로 실행하고 싶을 때만 누르면 됩니다. 보관된 건이 엑셀에 또 들어 있어도 다시 살아나지 않고 건너뜁니다.
